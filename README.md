# Cybersecurity GRC Risk and Compliance Assessment

## Project Overview

This repository contains a practical Cybersecurity Governance, Risk and Compliance (GRC) assessment covering two organisational security scenarios.

The project explores how organisations can respond to cybersecurity incidents, manage regulatory obligations, protect sensitive information, implement information security controls, and maintain security when adopting cloud infrastructure.

The assessment demonstrates the application of cybersecurity governance and risk management principles to realistic business environments.

## Project 1: ShieldCover Assurance – Cyber Incident Response and Regulatory Compliance

This project examines a cybersecurity incident involving ShieldCover Assurance, where an unpatched internet-facing VPN appliance was compromised, approximately 500,000 customer records were exposed, and ransomware affected internal file servers.

The exposed information included National Identification Numbers (NINs), bank details, and identity documents.

### Key Areas Covered

* Cybersecurity incident response and containment.
* Nigeria Data Protection Act (NDPA) breach notification requirements.
* Regulatory reporting to the Nigeria Data Protection Commission (NDPC).
* Customer breach notification and communication.
* Ransomware and cyber extortion policy.
* Evidence preservation and forensic investigation.
* Business recovery and disaster recovery planning.
* Cybersecurity risk remediation and management oversight.

### Project Objective

To develop a structured incident response and recovery approach that addresses regulatory obligations, protects affected customers, preserves evidence, and strengthens the organisation's cybersecurity posture.

## Project 2: T-Secure Pay – ISO 27001 Compliance and Cloud Security

This project examines the security considerations involved in migrating a financial services organisation from an on-premises environment to a hybrid cloud infrastructure using Amazon Web Services (AWS).

The assessment focuses on protecting sensitive customer and financial information during cloud adoption.

### Key Areas Covered

* ISO/IEC 27001:2022 information security controls.
* ISO Annex A.5.15 – Access Control.
* ISO Annex A.8.24 – Use of Cryptography.
* Nigeria Data Protection Regulation (NDPR) security considerations, as discussed in the assessment.
* AWS Shared Responsibility Model.
* Cloud identity and access management.
* Data encryption at rest and in transit.
* Cloud security monitoring and logging.
* Backup, recovery, and migration safeguards.
* Third-party and cloud security risks.

### Project Objective

To demonstrate how selected ISO 27001 controls can support the protection of personal and financial information and clarify the security responsibilities shared between AWS and its customer.
